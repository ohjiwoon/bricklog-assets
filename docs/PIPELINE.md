# 자동화 구조와 구현 순서

## 목표 흐름
| 단계 | 어디서 | 자동 여부 |
|---|---|---|
| 1. 공모주 일정·수요예측 결과 수집 | 클라우드 (Claude Code 예약 실행) | 자동 |
| 2. 수치 대조 (출처 2곳 이상) | 클라우드 | 자동. 불일치·단일 출처 → 🔍 + '수치 확인 필요' |
| 3. `data/ipo/<slug>.json` 생성 → `make_cards.py` → `ipo/<slug>/` push | 클라우드 | 자동 |
| 4. 원고 2벌 생성: 검수본(🔍·출처 포함) / 발행본(표시 제거, 🟧 위치 정보만) | 클라우드 | 자동 |
| 5. 노션 콘텐츠 DB에 페이지 생성 + 이미지 4장 첨부(GitHub raw → source_url) | 클라우드 | 자동 |
| 6. 검수 (🟨 작성, 🔍 확인, 상태 → 발행 준비) | 지운, 아무 기기 | 수동 |
| 7. 네이버 에디터 입력 매크로 | **지운 PC** (로그인된 브라우저) | 자동, **발행 직전에서 멈춤** |
| 8. 발행 버튼 + 발행 URL 노션 기록 | 지운 | 수동 |
| 9. 아카이브 (발행본 Markdown + 이미지) | 클라우드 | 자동 |

## 원칙
- **미확인 수치가 있으면 5단계 상태를 '발행 준비'로 올리지 않는다.** 7단계 매크로는 '발행 준비' 상태만 처리한다.
- 숫자를 고치면 JSON 하나만 수정 → 카드 재생성 → 노션 이미지 교체.
- 이미지는 고정 템플릿. AI 생성 이미지 쓰지 않음.
- 비밀값(Gemini 키, 노션 토큰)은 환경 변수 또는 GitHub Secrets. 저장소·채팅 금지.

## 네이버 매크로 (7단계) 주의
- 네이버는 매크로를 어뷰징으로 제재할 수 있다. 위험이 0은 아니라는 걸 지운이 알고 진행.
- **2단계 인증을 끄지 않는다.** 이미 로그인된 브라우저 프로필을 재사용한다(Playwright persistent context 등).
- 제목 입력 → 본문 블록 입력 → 이미지 4장 업로드(위치대로) → 🟧 문장 글자색 #FF7A45 → 해시태그 → 카테고리 '공모주' 선택 → **임시저장 후 멈춤**. 발행은 지운이 누른다.
- 하루 발행량을 늘리지 않는다(도배로 보일 수 있음). 사람 속도에 가깝게 입력 간격을 둔다.
- 스마트에디터 구조가 바뀌면 깨질 수 있으니, 실패 시 원고·이미지를 수동 붙여넣기용으로 내보내는 대체 경로를 둔다.

## Gemini 2차 검증 (선택)
- 지운 희망 모델: Gemini 3.5 Flash Lite (무료 한도 표기: 분당 15회 / 분당 25만 토큰 / 일 500회).
- 클라우드 작업 환경에서는 Gemini API가 막혀 있었음 → GitHub Actions에서 실행하는 방식 제안.
- 입력: data JSON + 출처 텍스트 / 출력: 항목별 일치·불일치. 불일치 → 노션 메모와 상태 반영.

## 자동화 설계 (2026-11-05 갱신)

전제: 글 품질이 먼저다. 자동 발행 전에 리터치를 몇 번 거쳐 규칙을 쌓는다.

### 지운이 하는 일: 노션에서 세 가지만 (2026-11-06 지운 확인)
1. 내용을 리터치한다
2. 페이지 제목 칸에 최종 제목을 직접 쓴다 (번호 고르기 대신)
3. 최종 체크 표시를 한다 = 트리거. 네이버 임시저장까지 자동, 발행은 지운

트리거는 체크 하나로 끝낸다. 네이버 로그인은 전용 프로필에 유지되어 보통 다시 하지 않고, 풀리면 매크로가 멈추고 알린다. 지운 PC가 켜져 있어야 입력이 돈다.

### 단계
| 단계 | 내용 | 실행 위치 | 상태 |
|---|---|---|---|
| 1. 일정 감지 | `collect_38.py --list` + 최근 기사로 정정 일정 대조 | 미정(아래) | 수집기 완성 |
| 2. 자료 수집 | `collect_38.py <번호>` + DART + 기사 → `data/ipo/raw/` | 미정(아래) | 38 완성, DART 미착수 |
| 3. 시황 | 코스피·코스닥 5·20거래일, 큰 이슈 일정, 최근 상장주 성적 | 미정(아래) | 수동 |
| 4. 대조 | 수치별 출처 2곳. 불일치·단일 출처는 메모에 기록 | Claude | 수동 |
| 5. 카드 | `make_cards.py` → GitHub push | Claude | 완성 |
| 6. 원고 | POST_TEMPLATE 규칙 + 제목 10안 → 노션 | Claude | 수동 |
| 7. 리터치 | 지운이 노션 수정, 피드백은 규칙에 반영 | 지운 | 진행 중 |
| 8. 네이버 입력 | 트리거 감지 → 입력 → 정지 또는 예약 | 지운 PC | 미착수 |
| 9. 기록 | 발행 URL을 노션에 기록, 상장일 복기 예약 | Claude | 미착수 |

### 실행 위치 (미검증)
- 수집은 지운 PC가 꺼져 있어도 돌아야 한다. 후보: GitHub Actions에서 수집 → Claude 예약 실행이 원고 작성.
- 클라우드에서 38 접속이 막힐 수 있다(과거 기록). 먼저 시험한다. 막히면 우회하지 않고 PC 수집으로 간다.
- 저장소가 public이라 수집 원문은 커밋하지 않는다. private 저장소나 Actions 임시 파일로 넘긴다.
- 네이버 입력은 로그인된 브라우저가 필요해 PC에서만 돈다.

### 리터치 → 자동화 전환 기준
- 발행본을 노션 원고와 비교해 지운이 고친 곳을 규칙으로 옮긴다.
- 연속 2~3편에서 내용 수정 없이 제목 선택만으로 발행되면 자동 초안을 켠다. 기준은 지운이 정한다.

### 네이버 매크로 규칙 (발행 글 3편 분석, 2026-11-05)
저장한 발행본에서 확인한 결과:
- 오렌지: 3편 모두 색이 없고 굵은 글씨만 남았다. 매크로가 #FF7A45를 적용해야 한다.
- 줄바꿈: 문단 사이 빈 줄이 있기도 하고 없기도 하다. 규칙: 문단 사이 빈 줄 1개, 한 문단 80자 안쪽, 소제목 바로 아래는 빈 줄 없음, 표·이미지 앞뒤도 빈 줄 없음.
- 표: 발행본에 배경·테두리 스타일이 없다. 가운데 정렬과 첫 행 굵게만 남았다.
- 해시태그: 본문 줄이 아니라 태그 칸에 넣는다. 본문 해시태그 줄은 뺀다.

### 네이버 매크로 재시험 조건 (2026-11-06)
전용 브라우저로 로그인을 반복한 직후 네이버 아이디 보호조치가 떴다. 원인은 미확정. 지운이 해제 후 재시험을 결정했다.
- 범위: 노션 확인 → 임시저장. 발행은 지운.
- 로그인은 1회, '로그인 상태 유지' 켬. 실패해도 반복하지 않는다.
- 보호조치나 보안 확인이 다시 뜨면 즉시 멈추고 매크로를 접는다. 탐지 회피는 쓰지 않는다.
- 하루 1편.
- 에디터 선택자는 auto-naver-blog의 실측값(2026-08-25)을 참고하되 inspect 결과로 확인한다.
- 재시험 결과(2026-11-06): 로그인 때 보안 질문이 나왔고 답한 뒤 '다시 로그인해 주세요'로 돌아왔다. 조건대로 멈췄다. `editor.py` 로그인 시도 금지.

### 현재 방식: 복사 페이지 (2026-11-06 지운 결정)
네이버 자동 입력 대신 `scripts/naver/copy_page.py`로 복사 페이지를 만들고, 지운이 평소 Chrome에서 붙여넣는다. 네이버에는 프로그램이 접속하지 않는다.

흐름(지운 결정): 노션 리터치 → 지운이 최종 체크 → `scripts/naver/watch_notion.py`가 1분마다 확인해 복사 페이지 생성 → '복사 페이지' 칸에 주소 기록, 체크 해제, Chrome에서 열고 알림 → 붙여넣기. 지운 PC에서 launchd로 돈다. 실패하면 체크를 두고 메모에 이유를 적는다. 토큰은 `~/.bricklog/notion.env`(권한 600).

### 네이버 매크로 구현 (중단)
- `scripts/naver/format_post.py`: 노션 원고 → html·image 블록과 tags
- `scripts/naver/editor.py`: 전용 프로필로 `login`, 에디터 구조를 저장하는 `inspect`
- 다음: inspect 결과로 입력 기능 작성. 임시저장까지만 자동, 발행은 지운이 누른다.
- 실행 위치: 지운 PC. 네이버 위험은 줄일 뿐 없앨 수 없고, 탐지 회피와 캡차 우회는 넣지 않는다.

## 구현 순서 (2026-11-05 갱신)
1. 38 수집기 `scripts/collect_38.py` (완료, 세 종목 시험)
2. 수집기로 다음 공모주 글을 쓰며 리터치 반복
3. DART(OpenDART API, 키 필요)로 투자설명서 항목 보강
4. 노션 트리거: '제목 번호' 속성, 검수 로직
5. 네이버 입력 매크로 (첫 발행 링크 확인 후)
6. 예약 실행과 클라우드 수집 시험
7. 상장일 복기·근황 템플릿, 월간 캘린더, 위클리 매크로 체크

### 노션 대시보드 (2026-11-06)
- 페이지: 브릭로그 대시보드 (`410488d6e9fa8119acb0caa033939e68`), 안에 '공모주 캘린더' DB (청약 달력, 진행판, 상장 달력, 전체 표)와 콘텐츠 DB 발행 현황 보기.

- 시황 줄은 장중 값을 빼고 끝난 날 종가만 쓴다. Yahoo 일별 값이 빠지는 날이 있어 참고용으로만 표시한다.
