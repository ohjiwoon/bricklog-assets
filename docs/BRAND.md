# 브랜드 디자인

원본: `brand/BRICKLOG_Brand_Guide_v1.pptx`, 로고 `brand/logo.png`, 카드용 캐릭터 `brand/character.png`

## 정체성
- 공식 한글명 **브릭로그**, 영문 BRICKLOG는 보조. 슬로건: 하나씩 쌓아가는 투자자의 기록
- BRICK = 투자 원칙과 경험을 차곡차곡 쌓는 과정 / LOG = 시장 관찰, 분석, 판단, 복기 기록
- 투자 철학: 계좌관리 우선 · 시황 중심 · 엇박을 피하는 판단
- 성격: 친근함(어렵지 않은 말) · 위트(가벼운 표정, 진지한 내용) · 꾸준함 · 신뢰(과장보다 근거와 원칙)

## 서체
- Pretendard (ExtraBold/Black 제목, SemiBold/Medium 본문). `make_cards.py`가 npm에서 자동으로 받는다.
- 대체 후보: 여기어때 잘난체 고딕, G마켓 산스 Bold (라이선스 확인 필요)

## 캐릭터
- 오렌지 벽돌, 흰 모자에 초록 상승 화살표, 검은 선글라스, 장난기 있는 표정, 두꺼운 외곽선
- 작은 크기에서는 소품을 줄인다. 새 포즈(IPO 카드, 돋보기 등)는 GPT로 따로 그려야 한다.
- `character.png`는 로고에서 모자 끝(y=13)부터 잘라냈고, 오른쪽 아래 노란 손 조각은 지웠다. (11/5 모자 잘림 수정)

## 블로그 썸네일 규칙 (가이드)
- 1:1, 제목 2~3줄 이내, 회사명·핵심 키워드를 가장 크게, 캐릭터는 보조, 중앙 안전영역 확보
- 유지: 로고·캐릭터·태그 위치·카테고리 컬러 / 교체: 기업명·주제·날짜·핵심 메시지
- 금지: 과도한 상승 암시, 과장 문구, 복잡한 배경
