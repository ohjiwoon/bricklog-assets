# 네이버 블로그 꾸미기 체크리스트 (진행 예정)

참고 시안: GPT가 만든 '네이버 블로그 꾸미기 가이드' 이미지(모바일 앱 화면 기준). 시안의 이웃·구독자·조회수 숫자와 아직 없는 글 카드는 가짜다.
메뉴 이름은 네이버 업데이트로 조금 다를 수 있다.

## 이미지 준비
- PC 타이틀 배너: 가로 966px × 세로 300~400px (시안의 1920×460은 네이버 PC 규격과 다름)
- 모바일 커버: 정사각형에 가깝게 1080px 이상, 캐릭터·로고는 중앙
- 프로필: 400×400, 캐릭터 얼굴
- 카테고리 아이콘 6종: 새 포즈가 필요하면 GPT로

## PC (내 블로그 → 관리)
- [ ] 1. 기본 설정 → 블로그 정보: 블로그명·별명 '브릭로그', 소개글 "하나씩 쌓아가는 투자 기록. 공모주·기업·시황을 브릭로그 기준으로 정리합니다.", 주제 비즈니스·경제, 프로필 이미지
- [ ] 2. 메뉴·글·동영상 관리 → 블로그 카테고리: 공모주 → 기업분석 → 시황분석 → 투자기록 → 공부노트 → 생각노트 (시안의 '시장전망'은 '시황분석'으로 통일), 글 보기 앨범형
- [ ] 3. 메뉴 관리 → 상단 메뉴: 공모주·기업분석·시황분석·투자기록 / 프롤로그 켜기(이미지 강조형)
- [ ] 4. 꾸미기 설정: 기본 단색 스킨, 레이아웃 1단(또는 2단 오른쪽 사이드), 위젯은 프로필·카테고리·검색만
- [ ] 5. 세부 디자인(리모콘): 배경 #FFF6E8, 타이틀 직접 등록(블로그 제목 글자 숨김), 메뉴 글자 #3B230F·강조 #FF7A45, 포스트 영역 흰색, 위젯 테두리 연한 베이지
- [ ] 6. 공지글 '[안내] 브릭로그 블로그 소개 & 콘텐츠 가이드' (소개 2줄, 카테고리 6개, BRICK CHECK 기준표, 면책) → 공지사항 등록

## 모바일 (앱 → 내 블로그 → 홈편집)
- [ ] 7. 큰 이미지 커버 스타일 + 모바일 커버, 대표글(공지)·최신글만 켜기
- [ ] 8. PC·모바일 로그아웃 상태로 확인, 썸네일이 카드에서 잘리지 않는지 확인

참고: 클라우드 작업 환경에서는 네이버 블로그 관리 화면을 브라우저로 조작할 수 없었다(안전 제한). 단계별 안내 + 지운 캡처 확인 방식으로 진행.
